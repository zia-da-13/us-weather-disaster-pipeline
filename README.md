# U.S. Weather & Disaster Intelligence Pipeline

A data engineering project that collects weather and natural disaster data
from public APIs, transforms the data, stores it in a database, and prepares
it for analytics and visualization.

## Technologies

- Python
- REST APIs
- PostgreSQL
- SQL
- Power BI
- Git
- GitHub

## Planned Data Sources

- National Weather Service API
- USGS Earthquake API
- NOAA Climate Data
